## Implementation Plan

<!-- SECTION:PLAN:BEGIN -->
Research done: traefik on nixos already proxies dockhand/zerobyte on roan via Tailscale (ipRegistry dockhand/zerobyte = roan.tailscaleIp 100.99.235.113). Same pattern applies to grafana/loki. Roan firewall trusts tailscale0, only opens 53 otherwise, so Tailscale inbound should pass without extra ports. Prometheus scrapes node exporters on :3021 via Tailscale hostnames, roan has tailscale.enable true.

Plan:
1. Confirm `ssh roan` tailscale status + MagicDNS resolve becca/bellamy + curl :3021/metrics
2. Choose routing: Option A keep traefik on nixos pointing to roan (minimal churn, matches dockhand precedent). Option B enable traefikk on roan (duplicate vHosts, DNS split) - not recommended
3. Update ipRegistry grafana/loki to hosts.roan.tailscaleIp, verify traefik routers grafana/loki resolve to roan:3010/3030
4. Verify firewall: no extra allowedTCPPorts needed for Tailscale due to trustedInterfaces, add LAN ports only if direct LAN access required
